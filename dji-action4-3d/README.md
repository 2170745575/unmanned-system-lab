# DJI Osmo Action 4 · 3D 拆解可视化

纯 **Three.js + HTML + CSS + JavaScript** 实现的单页 3D 拆解演示，跑在**共享引擎 `engine.js`** 上（与攻击 / 医疗 / 物流三个机型同一套引擎）。
所有几何体（机身、镜头、屏幕、主板、电池、磁吸底座……）与全部贴图**都由代码生成**，不依赖任何外部 3D 模型文件、图片或音频。

## 打开方式

两种都行：

1. **直接双击 `index.html`**（经典 script 标签加载，`file://` 下可用；启动配置走 `dsh-startup.js`）。
2. 或起个本地服务：`npx serve .` / `python -m http.server`，然后访问 `http://localhost:...`（启动配置走 `dsh-startup.json`）。

Three.js 加载顺序：**CDN 优先 → 3.5 秒超时或失败 → 自动回退 `vendor/three.min.js`**。
所以断网、内网、CDN 被墙都能正常打开（本地副本已随包提供）。

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面结构 + 全部样式（深色科技风 UI） |
| `model-action4.js` | **机型模块**：18 个部件的清单数据 + 几何建模 + 自带程序化贴图（`builderFactory` 自注册到 `window.DJIPage.model`） |
| `engine.js` | **共享引擎**（与其它机型逐字节一致）：加载器 / 场景灯光 / 轨道控制 / 拾取 / 爆炸拆解 / 战术 HUD / 参数面板 / 后期处理 / 演示巡航 / 技术图纸 / 中英双语 / 展台外壳 |
| `dsh-startup.json` | 启动动画配置（品牌字、标语、强调色、启动日志、tips、`aerial:false`）；`file://` 下读它的孪生 `dsh-startup.js` |
| `dsh-startup.js` | 同上（`file://` 用） |
| `vendor/three.min.js` | Three.js r149 本地副本（离线回退用，608 KB） |

脚本顺序必须是 `model-action4.js` → `engine.js`（引擎最后，按 `window.DJIPage.model` 装配）。

## 结构

- **部件（18 项）**：镜头保护镜圈、光学镜头模组、前置触摸屏、前面板外壳、1/1.3" 影像传感器、主控板、电池、散热模组、机身中框、后置触摸屏、快门键、QS 键、侧边电源键、接口仓盖、microSD 卡、扬声器、麦克风阵列、磁吸快拆底座。
- **拆解动画**：按部件序号阶梯推进（`easeInOutCubic`），同时相机自动拉远，保证爆炸图不出画。
- **高亮**：材质自发光脉冲 + 加法混合轮廓辉光 + 科技描边 + 中心辉光精灵。
- **标注**：HTML 标签 + SVG 引线，逐帧投影跟随部件。
- **贴图**：取景 UI、电池标签、PCB 走线、网罩、环境反射等全部由 `canvas` 程序化生成（`model-action4.js` 自带一份，不依赖引擎 TEX 的键）。
- **去塑料感**：所有材质经引擎 `std()` 咽喉点规范化（非金属件 metalness 压到近 0、补微表面法线 + 粗糙度噪声 + 环境反射），几何体在 `addMesh` 里烘焙顶点色 AO。
- **场景参数**：`rootScale: 1`（1 单位 = 1 cm，旧版无任何缩放）、`floorY: -3.05`、默认机位 `theta 0.62 / phi 1.24 / radius 11.5`，与旧版 `app.js` 逐项一致。

## 想改参数？

`model-action4.js` 里：

- `PARTS` 数组 —— 每个部件的名称、英文名、标注短参、拆解方向 `dir`、拆解位移 `dist`、功能介绍 `role`、参数表 `specs`。**加一个部件只需要在这里加一项 + 在 `BUILDER` 里写一个建模函数**（部件数需同步 `scene` 之外的自检项与 `index.html` 里的静态读数）。
- `BUILDER` 对象 —— 各部件几何体构建（1 单位 = 1 cm，机身 = 7.05 × 4.42 × 3.28）。
- `buildTextures()` —— 程序化贴图。
- `window.DJIModelAction4.scene` —— 默认视角、雾、地面网格、阴影范围、主光方向。
- `window.DJIModelAction4.tour` —— 演示巡航镜头脚本；`aerial/hoverAmp/flyLift` 控制"是否是飞行器"与漂移幅度。

> 参数依据公开资料整理，用于可视化演示，非工程图纸。

## 引擎提供的展台级能力

| 能力 | 说明 | 快捷键 |
| --- | --- | --- |
| **后期处理** | 泛光 + ACES 调色 + 暗角 + 颗粒，失败自动降级为直出 | — |
| **演示巡航** | 6 个镜头（含两次拆解总览）+ 影院遮幅 + 镜头说明 | `T` |
| **技术图纸** | 全机线框 + 换色 + 雾浓度降低 | `B` |
| **中英双语** | 部件名 / 按钮 / 面板 / 详情全部切换，偏好写入 `localStorage` | `U` |
| **启动动画配置化** | 读同目录 `dsh-startup.json`（`file://` 下读 `dsh-startup.js`）：品牌字、标语、强调色、启动日志逐行点亮、自动进入、tips | — |
| **展台外壳** | 返回展台按钮（顶栏）、音乐开关（Web Audio 程序化合成，零音频文件） | — |
| **状态自检扫描** | 青色双层光环下降扫描 + 右上角自检面板逐项点亮 | `S` |
| **模拟飞行** | 展示级漂移 + 姿态呼吸感（`aerial:false` 时不加航行灯 / 不冒充飞行器） | `F` |

`dsh-startup.json` 的 `aerial` 字段决定是否加航行灯（Action 4 为 `false`——它是相机不是飞行器）。
