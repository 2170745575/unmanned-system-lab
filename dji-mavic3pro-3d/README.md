# DJI Mavic 3 Pro · 3D 拆解可视化（共享引擎版）

纯 **Three.js + HTML + CSS + JavaScript** 实现的单页 3D 拆解演示：四轴机臂、三摄云台、机身内部堆叠——**全部几何与贴图由代码生成**，不依赖任何外部 3D 模型 / 图片 / 音频。整体风格是无人机作战体系的战术 HUD 界面。

本页已移植到**共享引擎**（与攻击 / 医疗 / 物流机型同一套 `engine.js`）：机型差异全部收敛到 `model-mavic.js`，引擎提供场景、轨道控制、拾取、爆炸拆解、战术 HUD、参数面板、后期泛光、演示巡航、技术图纸、中英双语、展台外壳、模拟飞行、航行灯、自检扫描。

## 打开方式

1. **直接双击 `index.html`**（经典 script 标签加载，`file://` 下可用）。
2. 或起本地服务：`npx serve .` / `python -m http.server`。

Three.js 加载顺序：**CDN 优先 → 3.5 秒超时或失败 → 自动回退 `vendor/three.min.js`**。断网 / 内网 / CDN 不可达都能打开。
页内自带启动看门狗：脚本报错、资源 404、或 18 秒未起来，都会直接把原因显示在页面上，不会一直转圈。

## 战术 HUD 构成

- **锁定框**：选中部件后，其实时投影包围盒被四角括号套住，虚线框 + `TGT-07 · LOCK 96%` 状态签。
- **遥测条**（左下）：ALT / HDG 由相机真实状态推导；旋转速度、拆解态会反映到机体状态。
- **迷你雷达**（右下）：把 23 个部件的俯视位置画成触点，扫描扇面持续旋转；选中部件为琥珀色。
- **3D 战术元素**：地面雷达扫描扇面、上下往复的扫描环、距离圈与方位刻度。
- **视觉层**：全屏扫描光带、四角战术框、中心准星、等宽字体标注（`P-15 三轴云台`）。

## 部件（23 项）

**机身结构**：机身上盖、机身中框、云台减震挂架
**动力系统**：左前 / 右前 / 左后 / 右后机臂（含无刷电机，后机臂集成起落架）、四支低噪快拆折叠桨
**相机与云台**：三轴云台、哈苏主相机（4/3 CMOS）、中长焦相机（1/1.3"）、长焦相机（1/2"）
**飞控与图传**：主板 / O3+ 图传模块、电调板、散热风扇
**感知与供电**：前视双目视觉、下视视觉 + 红外 ToF、智能飞行电池、接口仓盖、定位与天线模块

## 实现要点

- **机体曲面用超椭圆截面放样（loft）**：`loftGeo()` 沿 Z 逐段放样超椭圆截面，`part:'upper'/'lower'` 时按水平接缝剖开，天然得到「上盖 / 中框」两件且接缝端点严格重合——比堆圆角盒子好看得多，也让爆炸图的分件更符合真实结构。
- **曲面贴合细节**：`bodyTopAt(z)` / `bodyBottomAt(z)` / `bodyHalfWidthAt(z,y)` 查询放样曲面，把散热口、分模线、螺丝、装饰槽精确贴在曲面上，不靠肉眼估坐标。
- **单位**：建模用 cm（展开尺寸 347.5 × 283 × 107.7 mm 量级），整机根节点 `scene.rootScale = 0.5`（与旧版一致，保证整机尺寸不变）。
- **桨叶自旋**：桨叶沿用**绝对坐标**建模，机型模块只声明 `def.spin` 与 `def.spinAt`（桨毂中心），引擎把网格收进内层枢轴组实现自旋，并生成动态桨盘光晕（`def.rotor`）——建模代码零改动。
- **顶点色 AO + 去塑料感**：机型模块里所有几何体都经 `addMesh`（烘焙自下而上渐变的顶点色 AO），所有材质都经 `std / glass` 咽喉点（非金属 `metalness` 压到近 0、补微表面法线与粗糙度噪声），因此没有"无贴图的中间 metalness"材质。
- **性能**：辉光/描边叠加对象未高亮时 `visible = false`，省掉约 400 次 draw call；阴影贴图每 3 帧手工刷一次。
- **贴图**：PCB 走线、电池标签、哈苏镜筒铭牌、风扇网罩、环境反射等全部由 `canvas` 程序化生成（`model-mavic.js` 自带 `TEX`，不依赖引擎 `TEX` 里是否有对应键）。

## 想改参数？

`model-mavic.js` 里：

- `PARTS` —— 部件名称、英文名、标注短参、拆解方向 `dir`、拆解位移 `dist`（cm）、功能介绍 `role`、参数表 `specs`。
- `BODY_SECTIONS` / `BODY_SEAM` —— 机体截面表与上下壳接缝高度，**改机体外形主要就是调这张表**。
- `BUILDER` —— 各部件几何体构建；`MOTOR` / `CAM_Y` / `CAM_Z` / `FOOT_Y` 控制动力、相机与起落架位置。
- `propSpinAt(sx, sz)` —— 桨叶自旋中心；`PROP_R` —— 桨盘半径。
- `buildTextures()` —— 程序化贴图。
- `window.DJIModelMavic.scene` —— 取景与场景参数（`radius / theta / phi / minRadius / maxRadius / fog / gridSize / rootScale / keyLight`）。
