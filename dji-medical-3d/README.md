# MEDEVAC-1 · 大型医疗救援无人机可视化

纯 **Three.js + HTML + CSS + JavaScript** 的单页 3D 救护模拟：3 米级六旋翼医疗平台（增压医疗舱、担架、生命维持、血液冷藏、监护除颤、绞盘吊救、可抛投物资舱），**生命探测扫描 → 分诊定级 → 投送医疗物资 / 绞盘吊救后送 → 生命体征稳定**，全部几何由代码生成，不依赖任何外部模型与图片。

## 打开方式

双击 `index.html`（经典 script 标签，`file://` 可用），也可 `npx serve .`。
Three.js **CDN 优先 → 3.5 秒超时自动回退 `vendor/three.min.js`**；页内自带启动看门狗，加载失败会直接显示原因。

## 文件（与攻击无人机页共用同一套引擎）

| 文件 | 职责 |
| --- | --- |
| `index.html` | 页面结构 + 医疗风格样式 + 救护 HUD（伤员板 / 遥测 / 雷达 / 物资） |
| `engine.js` | **共享引擎**（与机型无关）：加载器、场景灯光、轨道控制、拾取、爆炸拆解、标注、战术 HUD、面板、渲染循环 |
| `model-medical.js` | 机型：30 个部件的数据 + 几何建构（六旋翼、医疗舱超椭圆放样） |
| `medical.js` | 救护行为：生命扫描、分诊、投送、吊救、特效、HUD 数据 |
| `casualties.js` | 伤员与医用地面道具：重伤员 / 轻伤员 / 帐篷 / 救护车 / 物资箱 / 输液架 / 地面标记 / 信标 / 烟雾 / 医疗十字 |

> 机型与行为通过 `window.DJIPage = { model, behavior }` 自注册，引擎不绑定任何机型 —— 这就是新增机型只需要加两个文件的原因。

## 救护机制

- **生命探测**：地面雷达扇面持续旋转，扫到伤员方位即确认生命体征（`TRACK`），1.8 秒后完成锁定。
- **分诊定级**：按血氧与心率自动分为 **危重 / 重伤 / 轻伤**，未救治者会持续恶化（血氧下降、心率上升），过晚则失去生命。
- **两种处置**：
  - **投送物资**：腹部物资舱沿缆绳降到伤员旁，投放血液与急救药品，落地后回收；伤员生命体征开始稳定。
  - **吊救后送**：危重伤员优先，吊篮降到地面固定伤员后起吊入舱，计入「已后送」。
- **物资管理**：血液 6 单位 / 药品 8 单位，用掉后逐步补给；自动模式下会优先吊救危重伤员。
- **批次推进**：本批全部处置完后自动接收下一批（数量与危重比例提升）。

## HUD

- **伤员板**（顶部）：编号、等级、距离、实时心率与血氧、处置状态与进度条；危重为红框、重伤琥珀、轻伤绿框、已失去灰化。
- **遥测**（左下）：ALT / SPD / HDG / CAS / PRI / HR / SpO₂ / PENDING / SAVED / LOST / EVAC。
- **迷你雷达**（右下）：自身部件绿点、伤员红点，BLOOD / DRUG 物资读数。
- **任务行**：MODE（SEARCH / TRIAGE / DEPLOY / RECOVER / STANDBY）+ 批次 + 已救治 + 待救治。
- **3D 锁定框**：已确认的伤员带四角括号与信息标签，选中部件为绿色锁定框。
- 地面医疗十字标记、信标、降落信号烟、救治完成的悬浮医疗十字（始终面向相机）。

## 实现要点

- 医疗舱用**超椭圆截面放样**（`n ≈ 3.8–5.0` 得到圆角硬朗的舱体），按水平接缝分成上盖与主体两件。
- 六旋翼机臂用放样锥形梁 + `placeAlong` 定向；三叶重载桨由 `bladeGeo` 程序化生成。
- 地面道具与伤员按 **cm 真实尺寸**建模，统一乘 `rootScale = 0.10`，与 3 米级无人机同场比例可信。
- **穿壳检查**：`_dji_selftest/diag-poke.js` 会按超椭圆内外面精确检查舱内部件是否穿出蒙皮（顶/腹外挂属正常安装），当前最大侧穿 1.3 cm。
- 投影前刷新 `camera.matrixWorldInverse`，锁定框与标签不慢帧；非高亮时叠加对象 `visible = false`；阴影贴图每 3 帧刷新一次。

## 参数在哪改

- `model-medical.js`：`SECTIONS` / `SEAM` 改舱体外形，`MOTOR_R` / `ARMS` 改旋翼布局，`parts` 改部件清单与参数，`scene` 改相机默认机位。
- `medical.js`：开头的 `RING_MIN/MAX`、`SCAN_WIDTH`、`VITAL_TIME`、`PROP_SCALE` 与各类计时器。
- `casualties.js`：伤员与地面道具的几何。

> 尺寸与参数为可视化演示用途，非任何真实装备的工程图纸。

## 展台功能（引擎级，快捷键）

- `T` **演示巡航**：电影级镜头轨迹自动推进 + 自动拆解巡展 + 影院遮幅
- `B` **技术图纸**：发光青色线框 + 深蓝背景，隐藏光晕特效，可无损还原
- `U` **中英双语**：部件清单、参数面板、3D 标注、按钮全部可切
- 后期处理：泛光（阈值 1.30 / 拐点 0.60 / 强度 0.60，按离线核对值标定）+ ACES 调色 + 暗角 + 胶片颗粒 + 轻微色差，WebGL2 走 4×MSAA，能力不足自动降级直出

URL 参数：`?mode=explode` / `?mode=tour` / `?mode=blueprint`。

### 展台外壳（引擎自带，页面无需改动）

- **返回展台**：顶栏按钮组首位注入「← 返回展台」，直达作品展台（`model.backUrl` 可覆盖）。刻意放进按钮组而不是固定定位，避免压住左上角品牌 Logo。
- **启动动画**：全屏入场层（旋翼图形 + 机型名 + 进度线 + ENTER），点击后淡出并播放 **1.7 秒镜头飞入**（相机从 2.35 倍机位缓动回默认机位，easeOutCubic）。7 秒无操作自动进入；带 `?mode=` 深链时直接跳过入场，保证门户跳转立刻进画面。
- **程序化音乐**：Web Audio 实时合成——低频氛围层（三个微失谐振荡器 + 缓慢律动的低通）、Am→F→C→G 和弦垫（每 9 秒换、长起音长释放）、空气噪声层、每 2 秒一记雷达脉冲；主增益仅 0.12，浏览器要求用户手势后才起播，开关状态存 `localStorage['dji-music']`。**零外部音频文件。**

### 去"塑料感"的材质体系

| 手段 | 说明 |
| --- | --- |
| metalness 二值化 | `std()` 咽喉点把非金属件的 metalness 从 0.22~0.4 一律压到 **0.04**（有贴图的碳纤维/PCB 例外）。中间值 metalness 是"塑料油光"的头号来源 |
| 微表面细节 | 程序化颗粒法线（128²，linear 不参与 sRGB 解码）+ 粗糙度噪声图，打散均匀高光；金属件改用方向性拉丝法线 |
| 顶点色 AO | `addMesh` 里给几何体烘焙 `color` 属性（按包围盒 Y 从 0.78 渐变到 1.06 + ±3% 哈希噪声）。不做昂贵射线遮蔽，但足以消除"整体一样亮"的塑料感 |
| 环境反射 | 重建摄影棚等距柱状环境图：陡峭的天顶/地平线对比 + 贯穿全宽的柔光带 + 冷主光/暖侧光/地面反光三处高光块 + 一条锐利地平线，金属终于有东西可反射 |
| 极光滑件豁免 | roughness < 0.2 的镜头玻璃不加细节法线，避免反射出现颗粒感 |

自动化断言（`smoke-flycart.js`）：**312 种材质中"无贴图的中间 metalness"材质数为 0**；顶点色样本范围 0.78~1.09。

## 展示级动态（让模型"活起来"）

| 能力 | 说明 | 快捷键 |
| --- | --- | --- |
| **模拟飞行** | 低频利萨茹漂移 + 升降 + **按位移速度推出的滚转/俯仰** + 缓慢偏航摆动，整机真的像在飞；地面有**桨下洗流环**与机腹光池脉动 | `F` |
| **航行灯 / 防撞灯** | 有旋翼的机型自动布灯：左红右绿航行灯、机顶白色信标、机背机腹红色防撞灯。红色用**航空式双闪**（每 1.35s 一个周期：亮 70ms、灭 130ms、亮 70ms、长灭），白色信标每 1.7s 闪一次 | — |
| **雷达自检扫描** | 一道青色光环从机体上方缓慢下降、边转边扫，同时右上角弹出**自检面板**逐项点亮子系统；扫完显示"全系统状态正常"。进入展台后自动跑一次，之后每 26 秒一次 | `S` |

行为层自己负责机体位移的机型（物流吊运 / 医疗吊救）会在 `behavior` 上声明 `movesRoot: true`，展示层就只保留姿态呼吸感——否则漂移量会顶住行为层的收敛阈值把状态机卡住。

## 启动动画配置：dsh-startup.json

每个页面目录下都有 `dsh-startup.json`（规范配置）与 `dsh-startup.js`（它的 file:// 孪生文件，内容一致）。启动动画的品牌字、标语、强调色、启动日志、自动进入时长、音乐默认值、是否进场自检全部从这里读：

```json
{
  "brand": "UNMANNED SYSTEM LAB",
  "kicker": "COMBAT READINESS · SELF-TEST",
  "title": "FELON-1 攻击无人机",
  "subtitle": "ARMED STRIKE QUADCOPTER · 24 PARTS",
  "accent": "#e8722a",
  "accent2": "#4fd6e8",
  "autoEnterMs": 7000,
  "music": true,
  "scanOnEnter": true,
  "tips": ["T 演示巡航", "B 技术图纸", "U 中英切换"],
  "bootLines": ["AIRFRAME INTEGRITY .......... OK", "MISSION SYSTEM READY"]
}
```

**读取顺序**：`window.DSH_STARTUP` → `fetch('dsh-startup.json')`（HTTP 服务下）→ 动态注入 `dsh-startup.js`（`file://` 双击打开时浏览器会拦本地 fetch，所以走这个孪生文件）→ 引擎内置默认。**三档都有兜底，任何一档失败都不影响页面。**

> 改启动动画：用 HTTP 服务跑就改 `dsh-startup.json`；直接双击打开就改 `dsh-startup.js`，两者内容保持一致。
