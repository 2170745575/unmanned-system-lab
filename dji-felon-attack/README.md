# FELON-1 · 攻击无人机作战可视化

纯 **Three.js + HTML + CSS + JavaScript** 的单页 3D 作战演示：军绿装甲机身、下挂武器站（30mm 机炮 + 弹药 + 后坐缓冲器 + 导弹挂架），**雷达扫描 → 识别 → 锁定 → 机炮扫射 / 导弹打击 → 击毁 → 波次推进**，全部几何体由代码生成，不依赖任何外部模型与图片。

## 打开方式

双击 `index.html` 即可（经典 script 标签，`file://` 可用）；也可以 `npx serve .` / `python -m http.server`。
Three.js **CDN 优先 → 3.5 秒超时或失败自动回退 `vendor/three.min.js`**；页内自带启动看门狗，任何脚本报错/404/15 秒未起来都会直接把原因显示出来，不会一直转圈。

## 文件（引擎与机型分离）

| 文件 | 职责 |
| --- | --- |
| `index.html` | 页面结构 + 作战风样式 + 作战 HUD（目标板 / 遥测 / 雷达 / 武器状态） |
| `engine.js` | **共享引擎**：加载器、场景灯光、轨道控制、拾取、爆炸拆解、标注、战术 HUD、面板、渲染循环。与机型无关 |
| `model-attack.js` | 机型：24 个部件的数据 + 几何构建（军绿装甲机身用超椭圆放样） |
| `combat.js` | 作战行为：扫描、锁定、炮塔随动、机炮/导弹、爆炸特效、波次、HUD 数据 |
| `enemies.js` | 敌方地面目标与特效几何：坦克 / 装甲车 / 卡车 / 自行高炮 / 残骸 / 曳光弹 / 弹药 / 爆炸 |
| `vendor/three.min.js` | Three.js r149 本地副本（离线回退） |

> **做医疗无人机时**：`engine.js` + `enemies.js` 直接复用，只需新写一个 `model-medical.js`（换部件与几何）和一个 `medical.js`（换行为：伤员识别、投送、撤离路线…），页面按同样顺序引入即可。

## 作战机制

- **扫描**：地面雷达扇面持续旋转，扇面扫到某个目标方位即判定"发现"，目标出现 `TRACK` 状态并从 0 涨到 100% 锁定（约 1.5 秒）。
- **交战**：锁定后自动交战会选出最近的已锁定目标；武器站方位座与机炮俯仰伺服随动瞄准，瞄准则命中（线段—球体判定，子弹再快也不会跳帧打空）。
- **两种火力**：机炮 60 发（600 发/分，5 发一组，打光需要等补给）；导弹 2 枚（对 22 单位外的远处目标自动补射，溅射伤害半径 9 单位）。
- **反馈**：命中火花、枪口火光、炮身后坐、屏幕震动与闪光、弹壳/曳光、导弹烟迹、击毁爆炸 + 火球 + 残骸替换。
- **威胁**：自行高炮会朝机体打曳光，命中会掉战损（HULL）；5 秒无命中开始自修。
- **波次**：清空当前波次后 3 秒自动投放下一波，数量与血量随波次提升。

## HUD

- **目标板**（顶部）：每个目标的编号、类型、距离、状态（IDLE / TRACK / LOCK / DESTROYED）与血条或锁定进度条。
- **遥测**（左下）：ALT / SPD / HDG / TGT / LOCK / THREAT / AMMO / MSL / HULL —— 全部由真实战斗状态推导。
- **迷你雷达**（右下）：自身部件为绿点，敌人为红点（锁定目标带红圈），扇面随扫描旋转。
- **任务行**：MODE（SEARCH / TRACK / ENGAGE / FIELD-MAINT）+ WAVE + KILL + THREAT。
- **锁定框**：选中部件为琥珀色四角括号；已发现的目标在 3D 场景中也有红色锁定框（最多 6 个，按锁定度排序）。
- 雷达扫描扇面、上下扫描环、距离圈、方位刻度、全屏扫描带、中心准星。

## 实现要点

- **机体曲面**用超椭圆截面放样（`loftGeo`），按水平接缝剖成上盖/中框两件，接缝端点严格重合。
- **武器站三轴**：`turretYaw` / `cannon` / `ammoDrum` / `recoilDamper` 共用 `pivot` 轴心，引擎支持 `def.pivot`，运行时直接设 `rotation.y`（方位）与 `rotation.x`（俯仰，`order='YXZ'`）。
- **部件 pivot 与包围盒**：`createPart` 在设置 `group.position` 之前量取包围盒，保证 `localBox` 是真正的局部坐标（锁定框才不会偏移）。
- **投影同步**：每帧在投影标注前刷新 `camera.matrixWorldInverse`，否则锁定框会慢一帧。
- **性能**：辉光/描边叠加对象未高亮时 `visible=false`。

## 想改参数？

- `model-attack.js`：`SECTIONS`/`SEAM` 改机体外形；`MOTOR`/`TURRET`/`RAIL` 改动力与武器站位置；`parts` 改部件清单与参数。
- `combat.js`：开头的 `SPAWN_R_MIN/MAX`、`SCAN_WIDTH`、`LOCK_TIME`、`ENEMY_SCALE` 以及 `update()` 里的射速/冷却/补给参数。
- `enemies.js`：敌方各型载具与特效的几何。
- `model-attack.js` 的 `scene` 段：相机默认机位、雾、地面环半径、阴影范围。

> 参数与结构为可视化演示用途，非任何真实装备的工程图纸。

## 展台功能（引擎级，快捷键）

- `T` **演示巡航**：电影级镜头轨迹自动推进 + 自动拆解巡展 + 影院遮幅
- `B` **技术图纸**：发光青色线框 + 深蓝背景，隐藏光晕特效，可无损还原
- `U` **中英双语**：部件清单、参数面板、3D 标注、按钮全部可切
- 后期处理：泛光（阈值 1.30 / 拐点 0.60 / 强度 0.60，按离线核对值标定）+ ACES 调色 + 暗角 + 胶片颗粒 + 轻微色差，WebGL2 走 4×MSAA，能力不足自动降级直出

URL 参数：`?mode=explode` / `?mode=tour` / `?mode=blueprint`。

### 展台外壳（引擎自带，页面无需改动）

- **返回展台**：顶栏按钮组首位注入「← 返回展台」，直达作品展台（`model.backUrl` 可覆盖）。刻意放进按钮组而不是固定定位，避免压住左上角品牌 Logo。
- **启动动画**：全屏入场层（旋翼图形 + 机型名 + 进度线 + ENTER），点击后淡出并播放 **1.7 秒镜头飞入**（相机从 2.35 倍机位缓动回默认机位，easeOutCubic）。7 秒无操作自动进入；带 `?mode=` 深链时直接跳过入场，保证门户跳转立刻进画面。
- **程序化音乐**：Web Audio 实时合成——低频氛围层（三个微失谐振荡器 + 缓慢律动的低通）、Am→F→C→G 和弦垫（每 9 秒换、长起音长释放）、空气噪声层、每 2 秒一记雷达脉冲；主增益仅 0.12，浏览器要求用户手势后才起播，开关状态存 `localStorage['dji-music']`。**零外部音频文件。**

### 去"塑料感"的材质体系

| 手段 | 说明 |
| --- | --- |
| metalness 二值化 | `std()` 咽喉点把非金属件的 metalness 从 0.22~0.4 一律压到 **0.04**（有贴图的碳纤维/PCB 例外）。中间值 metalness 是"塑料油光"的头号来源 |
| 微表面细节 | 程序化颗粒法线（128²，linear 不参与 sRGB 解码）+ 粗糙度噪声图，打散均匀高光；金属件改用方向性拉丝法线 |
| 顶点色 AO | `addMesh` 里给几何体烘焙 `color` 属性（按包围盒 Y 从 0.78 渐变到 1.06 + ±3% 哈希噪声）。不做昂贵射线遮蔽，但足以消除"整体一样亮"的塑料感 |
| 环境反射 | 重建摄影棚等距柱状环境图：陡峭的天顶/地平线对比 + 贯穿全宽的柔光带 + 冷主光/暖侧光/地面反光三处高光块 + 一条锐利地平线，金属终于有东西可反射 |
| 极光滑件豁免 | roughness < 0.2 的镜头玻璃不加细节法线，避免反射出现颗粒感 |

自动化断言（`smoke-flycart.js`）：**312 种材质中"无贴图的中间 metalness"材质数为 0**；顶点色样本范围 0.78~1.09。

## 展示级动态（让模型"活起来"）

| 能力 | 说明 | 快捷键 |
| --- | --- | --- |
| **模拟飞行** | 低频利萨茹漂移 + 升降 + **按位移速度推出的滚转/俯仰** + 缓慢偏航摆动，整机真的像在飞；地面有**桨下洗流环**与机腹光池脉动 | `F` |
| **航行灯 / 防撞灯** | 有旋翼的机型自动布灯：左红右绿航行灯、机顶白色信标、机背机腹红色防撞灯。红色用**航空式双闪**（每 1.35s 一个周期：亮 70ms、灭 130ms、亮 70ms、长灭），白色信标每 1.7s 闪一次 | — |
| **雷达自检扫描** | 一道青色光环从机体上方缓慢下降、边转边扫，同时右上角弹出**自检面板**逐项点亮子系统；扫完显示"全系统状态正常"。进入展台后自动跑一次，之后每 26 秒一次 | `S` |

行为层自己负责机体位移的机型（物流吊运 / 医疗吊救）会在 `behavior` 上声明 `movesRoot: true`，展示层就只保留姿态呼吸感——否则漂移量会顶住行为层的收敛阈值把状态机卡住。

## 启动动画配置：dsh-startup.json

每个页面目录下都有 `dsh-startup.json`（规范配置）与 `dsh-startup.js`（它的 file:// 孪生文件，内容一致）。启动动画的品牌字、标语、强调色、启动日志、自动进入时长、音乐默认值、是否进场自检全部从这里读：

```json
{
  "brand": "UNMANNED SYSTEM LAB",
  "kicker": "COMBAT READINESS · SELF-TEST",
  "title": "FELON-1 攻击无人机",
  "subtitle": "ARMED STRIKE QUADCOPTER · 24 PARTS",
  "accent": "#e8722a",
  "accent2": "#4fd6e8",
  "autoEnterMs": 7000,
  "music": true,
  "scanOnEnter": true,
  "tips": ["T 演示巡航", "B 技术图纸", "U 中英切换"],
  "bootLines": ["AIRFRAME INTEGRITY .......... OK", "MISSION SYSTEM READY"]
}
```

**读取顺序**：`window.DSH_STARTUP` → `fetch('dsh-startup.json')`（HTTP 服务下）→ 动态注入 `dsh-startup.js`（`file://` 双击打开时浏览器会拦本地 fetch，所以走这个孪生文件）→ 引擎内置默认。**三档都有兜底，任何一档失败都不影响页面。**

> 改启动动画：用 HTTP 服务跑就改 `dsh-startup.json`；直接双击打开就改 `dsh-startup.js`，两者内容保持一致。
