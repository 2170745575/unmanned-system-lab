# UNMANNED SYSTEM LAB · 无人系统可视化套件

> 纯前端、零外部资源的无人系统 3D 可视化作品集：**5 台机型 / 5 个可交互场景 / 1 套自研 Three.js 引擎**。
> 所有几何、贴图、材质、光照、后期处理与声效**全部由代码实时生成**——目录里没有一个模型文件、一张图片、一段音频。

## 二、作品内容

### 体系链路（作品的叙事主线）

五台机型不是孤立的模型，而是一条完整的无人系统链路，每台都对应一套可交互的任务模拟：

| 步骤 | 机型 | 部件 | 能力 | 目录 |
| --- | --- | ---: | --- | --- |
| 01 | DJI Mavic 3 Pro | 23 | 侦察感知 · 三摄云台 + 战术 HUD | `dji-mavic3pro-3d/` |
| 02 | FELON-1 攻击无人机 | 24 | 精确打击 · 扫描 → 锁定 → 炮塔随动 / 弹药打击 | `dji-felon-attack/` |
| 03 | MEDEVAC-1 大型医疗救援无人机 | 30 | 伤员后送 · 生命探测 → 分诊 → 绞盘吊救 | `dji-medical-3d/` |
| 04 | DJI FlyCart 100 物流无人机 | 30 | 物资投送 · 吊装 → 称重 → 消摆运输 → 投放 | `dji-flycart100-3d/` |
| — | DJI Action 4 运动相机 | 18 | 拆解交互的入门示例 | `dji-action4-3d/` |

**合计 125 个可拆解部件、3 套任务模拟、约 34 万三角面。**

### 展台级表现（引擎级，各页通用）

- **模拟飞行**：低频利萨茹漂移 + 按位移速度推出的**滚转/俯仰** + 缓慢偏航摆动，地面有桨下洗流环与机腹光池脉动——模型不是摆件，是在飞。
- **航行灯 / 防撞灯**：左红右绿航行灯、机顶白色信标、机背机腹红色防撞灯，红色用**航空式双闪**（亮 70ms / 灭 130ms / 亮 70ms / 长灭）。
- **雷达自检扫描**：一道青色光环从机体上方缓慢下降、边转边扫，右上角**自检面板**逐项点亮子系统，扫完提示"全系统状态正常"（进场自动一次，之后每 26 秒）。
- **电影级演示巡航**：6 个镜头位自动推进（含低角度特写、俯视拆解），自动在"合拢/拆解"间巡展，配影院遮幅与镜头说明。
- **技术图纸模式**：一键切换发光青色线框 + 深蓝背景，隐藏光晕特效，可无损还原。
- **中英双语**：部件清单、参数面板、3D 标注、界面按钮全部可切。
- **启动动画 + 程序化音乐**：全屏入场层（旋翼图形 + 启动日志逐行点亮 + ENTER）＋ 1.7 秒镜头飞入；音乐为 Web Audio 实时合成的低频氛围层 + Am→F→C→G 和弦垫 + 空气噪声 + 雷达脉冲。
- **后期处理**：自写泛光（亮部提取 + 两级高斯 + 合成）+ ACES 调色 + 暗角 + 胶片颗粒 + 轻微色差，WebGL2 走 4×MSAA。

## 三、引擎与代码结构

```
dji-hub/                 作品门户：动态线框主视觉、体系链路、机型卡片、技术亮点、双语
dji-felon-attack/        攻击型：engine.js + model-attack.js + combat.js + enemies.js
dji-medical-3d/          医疗型：engine.js + model-medical.js + medical.js + casualties.js
dji-flycart100-3d/       物流型：engine.js + model-flycart.js + flycart.js + logistics.js
dji-mavic3pro-3d/        侦察型：engine.js + model-mavic.js
dji-action4-3d/          影像型：engine.js + model-action4.js
```

**五个机型共用同一份 `engine.js`**（约 135 KB，五个目录里逐字节一致），机型只提供一个自注册文件（需要任务模拟时再加一个行为文件）：

- `model-*.js` —— 部件数据 + 几何构建（`window.DJIPage.model`，支持静态 `builder` 或 `builderFactory(H)` 两种形态）
- `*.js` —— 行为与任务模拟（`window.DJIPage.behavior`）

**新增一台机型 = 两个文件 + 门户里一条数据。**

### 值得一说的实现细节

| 主题 | 做法 |
| --- | --- |
| 几何 | 超椭圆截面放样机身、圆角挤出（ExtrudeGeometry + bevel）、程序化桨叶、共轴双桨反向自旋 |
| 贴图 | 碳纤维斜纹编织、PCB 走线、仪表玻璃划痕、微表面颗粒法线、方向性拉丝法线、粗糙度噪声，全部 canvas 程序化生成 |
| 去"塑料感" | ① 材质咽喉点 `std()` 把非金属 `metalness` 二值化到 0.04（中间值是塑料油光的根源）；② 微表面法线 + 粗糙度噪声打散均匀高光；③ `addMesh` 里烘焙**顶点色 AO**（包围盒 Y 渐变 0.78→1.06 + 哈希噪声）；④ 重建高对比度摄影棚环境贴图，让金属有东西可反射 |
| 物理 | 物流吊挂是**二阶摆方程**（`θ'' = -(g/L)sinθ - cθ' + 机体加速度项`），自动消摆=主动阻尼，HUD 实时显示摆角 |
| 模拟 | 三条独立状态机：扫描→识别→锁定→交战 / 探测→分诊→救护 / 吊装→称重→投放 |
| 冲突规避 | 行为层负责位移的机型在 `behavior.movesRoot` 上声明，展示层就不再写 `position`——否则每帧覆盖会擦掉行为累积的位移，把状态机卡死（这是开发中真实踩到的坑） |
| 性能 | 阴影贴图节流（每 3 帧）、非高亮叠加对象 `visible=false`、泛光半分辨率、`setPixelRatio ≤ 2` |

## 四、启动动画配置：`dsh-startup.json`

每个页面目录下都有 `dsh-startup.json`（规范配置）与 `dsh-startup.js`（它的 `file://` 孪生文件）。启动动画的品牌字、标语、强调色、启动日志、自动进入时长、音乐默认值、是否进场自检全部从这里读：

```json
{
  "brand": "UNMANNED SYSTEM LAB",
  "kicker": "COMBAT READINESS · SELF-TEST",
  "title": "FELON-1 攻击无人机",
  "accent": "#e8722a",
  "autoEnterMs": 7000,
  "music": true,
  "scanOnEnter": true,
  "bootLines": ["AIRFRAME INTEGRITY .......... OK", "MISSION SYSTEM READY"]
}
```

读取顺序：`window.DSH_STARTUP` → `fetch('dsh-startup.json')`（HTTP 服务下）→ 动态注入 `dsh-startup.js`（`file://` 双击时浏览器拦本地 fetch，走孪生文件）→ 引擎内置默认。**三档兜底，任何一档失败都不影响页面。**
带 `?mode=explode|tour|blueprint|sim` 的深链会跳过入场动画，保证门户跳转即时进画面。

## 五、质量保障

每台机型都有 Node 冒烟测试（`_dji_selftest/smoke-*.js`），按浏览器真实加载顺序加载全部模块，断言：

- **红线**：所有模块在 `THREE` 未加载时可安全执行（顶层绝不触碰 THREE）
- 模块数量与部件 id 完整性、DOM id 引用完整性
- 几何健全性：整机尺寸区间、部件数量、起落架不穿地、三角面数
- 机构功能：桨叶自旋与共轴反向、机臂折叠、吊运阶段机推进、实时称重、消摆开关对比
- 展台功能：巡航镜头推进、蓝图线框往返还原、中英切换、模拟飞行、防撞灯明暗周期、自检扫描完成度
- 材质体检：**312 种材质中"无贴图的中间 metalness"材质数为 0**；顶点色 AO 样本范围 0.78~1.09
- 兜底场景：CDN 完全挂住时的本地回退

### 穿模（浅穿）审计

`_dji_selftest/clip-audit.js` 用**真实几何点在内判定**做系统审计：对包围盒相交的部件对，取小件顶点、沿 +X 做射线穿越计数（投影到 (z,y) 平面），统计落在另一部件内部的顶点比例。比例 5%~45% = "只戳进去一点点"（浅穿候选），>60% 视为有意嵌套。

三个模型的实测结论：

| 机型 | 浅穿候选对 | 其中"非结构类"对 | 结论 |
| --- | ---: | ---: | --- |
| FELON-1 | 28 | **0** | 全部为结构结合（机臂入壳、上下壳对接、炮塔与弹鼓、GNSS 与飞控…） |
| MEDEVAC-1 | 24 | **0** | 全部为结构结合（六臂入舱、机头锥、绞盘、药架…） |
| FLYCART 100 | 35 | **0** | 全部为结构结合（四臂入壳、绞盘与电池仓、货箱释放机构…） |

也就是说：**没有发现"部件从蒙皮表面戳出来"的可见穿模**——命中的都是装配处的正常嵌套（外部看不见，拆解时会分开）。这与贴近视角的 PBR 渲染图上目视检查一致。
唯一一处真实的可见浅穿（攻击型机臂铰链座圆柱从机身肩部戳出约 0.5cm）是**目视**发现的，修法是让铰链沿机臂轴向内收 1.7cm（`HINGE_IN = 1.7`）——审计工具本身无法区分"正常装配"与"戳穿"，所以两者互补。

外观核对用自写 PBR 软件渲染器（`_dji_selftest/render4.py`，可选 `POST=1` 仿真后期管线），离线预测浏览器实际观感。

## 六、说明

- 所有尺寸与参数为**可视化演示用途**，非任何真实产品的工程图纸。
- 页面不联网也能跑（CDN 优先、3.5 秒超时回退 `vendor/three.min.js`；页内启动看门狗会把失败原因直接显示在屏幕上）。
- 音乐默认开启，但浏览器要求用户手势后才能起播（点「进入」或任意点击）；右上角随时静音，偏好写入 `localStorage`。
